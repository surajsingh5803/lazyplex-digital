## Review gates before publishing new content

1. **Evidence:** verify industry facts, approvals, prices, services and testimonials. Never invent case studies, offices, testimonials, outcomes or precise ranking claims.
2. **Intent:** assign one main query cluster and distinct reader decision to one URL; keep blogs educational and commercial pages service-led.
3. **Experience:** cite real sources, include original examples and separate illustrative models from client data.
4. **Technical:** one H1, unique title and description, self-canonical, internal links that resolve, schema based on actual content, sitemap entry if indexable.
5. **Conversions:** query parameters must match the service in the article or page. Do not equate click-to-call, directions or calls with unique qualified leads.
6. **Review:** run `node scripts/seo-quality-check.mjs` and verify the preview before merging; confirm actual GitHub Pages deployment separately.
